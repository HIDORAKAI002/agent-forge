# Contributors and testers wanted

Created and maintained by [HIDORAKAI002](https://github.com/HIDORAKAI002).

Thank you to everyone who reports a reproducible bug, tests on a real machine, improves documentation, reviews a security boundary or sends a pull request. We do not list unverified contributors or imply upstream authors endorse this project.

**Help especially wanted:** native Windows brokered filesystem/console isolation, standard-user Windows testing, Ruflo backend acceptance, Linux boundary regression testing, optional microphone/keyring acceptance and first-run documentation.

Start with [CONTRIBUTING.md](CONTRIBUTING.md), [the test guide](docs/TESTING.md), and [open issues](https://github.com/HIDORAKAI002/agent-forge/issues). Forks and focused PRs are welcome. Please share exact commits and redacted results, not credentials. Upstream projects are credited in [resources](docs/RESOURCES.md) and [third-party notices](docs/THIRD_PARTY.md).
